# City Walk

MVP гида по городу: карта с точками, уведомление при приближении к точке. Бэкенда нет — точки захардкожены в `src/points.ts`.

## Запуск

```bash
npm install
npm run dev
```

## Режимы

- `/` — обычный режим: «Начать прогулку» → браузер следит за геолокацией, при входе в радиус точки показывается карточка + звук (+ вибрация на Android).
- `/?debug` — геолокация не используется, клик по карте «перемещает» пользователя. Для тестов за столом.
- `/?admin` — клик по карте создаёт черновик точки и генерирует код для вставки в `src/points.ts`.

## Тест на телефоне

Геолокация работает только по HTTPS (кроме localhost). Варианты:
- задеплоить на Vercel/Netlify (`npm run build`, папка `dist`);
- или пробросить dev-сервер: `npx vite --host` + `ngrok http 5173`.

## Ограничения веб-версии

Отслеживание работает, только пока вкладка открыта и экран включён (экран удерживается через Wake Lock API). В фоне / с погашенным экраном уведомлений не будет — для этого нужно нативное приложение.
