# City Walk

MVP гида по Малаге: пользователь выбирает маршрут и идёт по остановкам, при приближении к остановке получает уведомление. Бэкенда нет — остановки и маршруты захардкожены в `src/routes.ts`, прогресс хранится в localStorage браузера.

## Запуск

```bash
npm install
npm run dev
```

## Режимы

- `/` — выбор маршрута → браузер следит за геолокацией, при входе в радиус остановки она засчитывается, показывается карточка + звук (+ вибрация на Android). Засчитывается любая остановка маршрута, даже если пользователь идёт не по порядку.
- `/?debug` — геолокация не используется, клик по карте «перемещает» пользователя. Для тестов за столом.
- `/?admin` — клик по карте создаёт черновик остановки и генерирует код для вставки в `STOPS` в `src/routes.ts`; затем добавьте её id в `stopIds` нужного маршрута.

## Тест на телефоне

Геолокация работает только по HTTPS (кроме localhost). Варианты:
- задеплоить на Vercel/Netlify (`npm run build`, папка `dist`);
- или пробросить dev-сервер: `npx vite --host` + `ngrok http 5173`.

## Ограничения веб-версии

Отслеживание работает, только пока вкладка открыта и экран включён (экран удерживается через Wake Lock API). В фоне / с погашенным экраном уведомлений не будет — для этого нужно нативное приложение.
